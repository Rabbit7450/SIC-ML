# NSL-KDD

Dataset académico de arranque para el Módulo 1.

```bash
python ids/ml/download_nsl_kdd.py
```

El distribuidor original de UNB indica que ya no aloja los archivos; el script usa el mirror público configurado en el proyecto. Consulta la cita y atribución NSL-KDD en el sitio de [UNB CIC](https://www.unb.ca/cic/datasets/nsl.html). Los TXT se mantienen locales y no se versionan.

CIC-IDS2017 es opcional y pesado: descargarlo solo cuando el pipeline NSL-KDD esté estable.
