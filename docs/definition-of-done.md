# Definition of Done

Una historia se da por cerrada solo si cumple las cuatro condiciones:

1. **Código en el repositorio** con commits claros (qué y por qué).
2. **Evidencia**: métricas, logs o capturas en `docs/evidencia/`.
3. **Documentación** actualizada en el README del módulo.
4. **Demostrable al tutor** en menos de 10 minutos.

Plantilla de evidencia por historia:

```
docs/evidencia/<sprint>-<historia>/
  README.md          # qué se demostró
  metricas.json      # si aplica
  captura-*.png      # Kibana, serial, etc.
  logs.txt
```
